# 项目名称：伙伴推荐站

## 项目介绍

知遇伙伴匹配是一套**全栈前后端分离的移动端 H5 平台**，核心解决在校学生、职场新人难以快速找到同方向、同目标学习伙伴 / 组队队友的痛点。

项目以**标签体系为核心**，实现了用户精准标签搜索、智能相似度匹配、全流程组队管理等核心功能，完整覆盖从需求设计、架构开发、性能优化、分布式方案到上线部署的企业级全流程。本项目基本覆盖了企业开发中常见的需求以及对应的解决方案，比如登录注册、批量数据导入、信息检索展示、定时任务、资源抢占等。并且涵盖了分布式、并发编程、锁、事务、缓存、性能优化、幂等性、数据一致性、大数据、算法等后端程序员必须了解的知识与实践。

从需求分析、技术选型、系统设计、前后端开发再到最后上线，除了学做项目之外，还能学会很多思考问题、对比方案的方式方法，并提升排查问题、解决 Bug 的能力。

## 前端

- Vue 3
- Vant UI 组件库
- TypeScript

## 后端

- Java SpringBoot 2.7.x 框架

- MyBatis-Plus

- Gson：JSON 序列化库
- 相似度匹配算法

## 核心功能特性

### 用户体系模块

用户注册、登录、退出登录，支持密码加密存储

基于 Redis 的分布式 Session，解决多机集群登录态同步问题

个人信息管理、标签编辑与自定义、个人队伍管理

精细化权限管控，区分普通用户与管理员权限

### 标签体系模块

多维度标签分类：性别、技术方向、学习内容、目标规划、能力段位、身份状态等

支持用户自定义标签，父子标签树形结构实现灵活分类管理

标签分组展示、标签快速筛选，适配搜索与匹配场景

### 精准搜索模块

支持多标签组合搜索，提供「同时匹配（AND）」「任意匹配（OR）」两种模式

关键词模糊搜索，支持队伍名称、描述、用户昵称多维度匹配

热点搜索结果 Redis 缓存优化，大幅降低数据库压力，提升响应速度

### 智能匹配模块

基于**编辑距离算法**实现用户标签相似度计算，自动推荐 TOP N 最匹配用户

优先队列优化 TOP N 计算，大幅降低内存占用，提升匹配效率

定时任务实现缓存预热，解决首页首次加载过慢问题，用户访问无感知提速

### 组队系统模块

队伍创建：支持设置队伍名称、描述、最大人数、过期时间、公开 / 私有 / 加密三种权限类型

队伍管理：支持队伍信息修改、解散、队长权限自动转移、过期队伍自动过滤

队伍加入 / 退出：支持密码校验加入、主动退出、人数上限管控、重复加入拦截

并发控制：基于 Redisson 分布式锁实现接口幂等性，高并发下保证人数不超限、数据一致性

队伍查询：分页展示队伍列表，支持关键词搜索、权限过滤，关联展示队伍成员信息

### 数据管理模块

基于 Easy Excel 实现百万级用户 Excel 数据批量导入、自动去重、数据清洗

支持第三方平台网页数据抓取，自动提取用户自我介绍中的标签信息并入库

自定义线程池 + 并发编程优化批量插入性能，大幅缩短大数据量入库耗时

基于 Swagger + Knife4j 自动生成后端接口文档，支持在线调试、参数说明、接口归档
